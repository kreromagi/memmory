# ❓ Часто задаваемые вопросы (FAQ)

## Общие вопросы

### Q: Нужно ли мне знать программирование для использования этого инструмента?
**A:** Нет! Приложение имеет графический интерфейс. Просто следуйте пошаговой инструкции в README.md. Программирование потребуется только если вы захотите интегрировать данные в свою нейросеть.

### Q: Сколько стоит использование?
**A:**
- **Figma API**: бесплатно (есть лимиты)
- **Supabase**: бесплатный план (до 500 МБ БД, 2 ГБ хранилища)
- **Netlify**: бесплатный план (100 ГБ трафика/месяц)
- **GitHub**: бесплатно

Для большинства дизайн-систем бесплатных планов достаточно!

### Q: Безопасны ли мои данные?
**A:** Да! Данные хранятся в вашей личной базе данных Supabase. Только у вас есть доступ к ключам. Рекомендуется:
- Не делиться API-ключами
- Использовать приватные репозитории на GitHub
- Регулярно обновлять токены

## Технические вопросы

### Q: Какие ограничения у Figma API?
**A:**
- **Запросы**: максимум 9 в минуту (приложение автоматически делает паузы)
- **Размер данных**: максимум 5 МБ за запрос
- **Rate limit**: 1000 запросов в час

### Q: Сколько времени занимает извлечение?
**A:** Зависит от размера файла:
- Маленькая система (5-10 страниц): 1-2 минуты
- Средняя система (20-30 страниц): 5-7 минут
- Большая система (50+ страниц): 10-15 минут

### Q: Можно ли синхронизировать несколько дизайн-систем?
**A:** Да! Просто используйте разные File ID. Все они сохранятся в одной базе Supabase.

### Q: Что делать, если файл очень большой?
**A:** Приложение работает постранично, поэтому размер файла не критичен. Главное — количество страниц и соблюдение лимита запросов.

## Проблемы и их решения

### Q: Ошибка "Failed to fetch" при синхронизации
**A:** Возможные причины:
1. Неверный API-ключ → Проверьте токен в Figma
2. Неверный File ID → Проверьте URL файла
3. Нет доступа к файлу → Убедитесь, что файл доступен вашему аккаунту
4. Истек срок токена → Создайте новый Personal Access Token

### Q: Ошибка "Rate limit exceeded"
**A:** Это нормально! Figma ограничивает запросы. Просто подождите 60 секунд и попробуйте снова. Приложение автоматически делает паузы, но иногда лимит все равно может быть достигнут.

### Q: Данные не сохраняются в Supabase
**A:** Проверьте:
1. Правильность Supabase URL и ключа
2. Выполнили ли вы SQL скрипт из `supabase-schema.sql`
3. Настройки RLS (Row Level Security) в Supabase
4. Логи в браузере (F12 → Console)

### Q: Приложение не открывается на Netlify
**A:** 
1. Проверьте статус деплоя: Netlify → Site → Deploys
2. Посмотрите логи сборки
3. Убедитесь, что все файлы загружены на GitHub
4. Попробуйте Trigger deploy → Clear cache and deploy site

### Q: В логах только первые страницы
**A:** Это нормально, если у вас много страниц. Приложение обрабатывает их последовательно с задержками. Дождитесь завершения процесса.

## Настройка и оптимизация

### Q: Можно ли изменить время задержки между запросами?
**A:** Да, но не рекомендуется уменьшать. В файле `src/services/figmaService.js` измените:
```javascript
this.requestDelay = 7000; // измените на нужное значение в миллисекундах
```
⚠️ Уменьшение может привести к блокировке!

### Q: Как добавить автоматическую синхронизацию?
**A:** Есть несколько вариантов:
1. **GitHub Actions**: создайте workflow для периодического запуска
2. **Zapier/Make**: настройте автоматизацию по расписанию
3. **Cron job**: на собственном сервере
4. **Netlify Functions**: serverless функции

### Q: Можно ли фильтровать, какие страницы извлекать?
**A:** Да! Измените в `src/services/figmaService.js`:
```javascript
const pages = fileData.document.children.filter(child => 
  child.type === 'CANVAS' && 
  child.name.includes('Components') // Например, только страницы с "Components"
);
```

### Q: Как экспортировать данные в другой формат?
**A:** После извлечения вы можете:
1. Скачать JSON через кнопку "Скачать JSON"
2. Экспортировать из Supabase в CSV/Excel
3. Написать скрипт для конвертации в нужный формат

## Интеграция с AI

### Q: Как подключить данные к ChatGPT?
**A:** Используйте OpenAI API с RAG (Retrieval-Augmented Generation). Пример в файле `AI-INTEGRATION-EXAMPLES.md`.

### Q: Можно ли использовать с Claude?
**A:** Да! Claude отлично работает с данными из Supabase. Используйте Anthropic API аналогично примерам с OpenAI.

### Q: Нужно ли создавать векторные embeddings?
**A:** Не обязательно, но рекомендуется для семантического поиска. Можно использовать:
- OpenAI Embeddings
- Supabase Vector Extension
- LangChain для обработки

### Q: Как часто нужно обновлять данные?
**A:** Зависит от частоты изменений вашей дизайн-системы:
- Активная разработка: раз в день
- Стабильная система: раз в неделю
- Редкие изменения: по необходимости

## Безопасность

### Q: Где хранить API-ключи в продакшене?
**A:** Используйте переменные окружения:
```javascript
// В Netlify: Site settings → Environment variables
const FIGMA_KEY = process.env.FIGMA_API_KEY;
const SUPABASE_URL = process.env.SUPABASE_URL;
```

### Q: Можно ли ограничить доступ к приложению?
**A:** Да! В Netlify:
1. Site settings → Visitor access
2. Enable password protection
3. Или используйте OAuth через Netlify Identity

### Q: Как защитить данные в Supabase?
**A:** Настройте Row Level Security (RLS):
```sql
-- Только для авторизованных пользователей
CREATE POLICY "Auth users only" ON design_systems
  FOR ALL USING (auth.uid() = user_id);
```
