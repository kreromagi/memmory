# 🚀 Быстрый старт

## За 5 минут до первого запуска

### 1️⃣ Supabase (2 минуты)
1. Откройте https://supabase.com → Sign up
2. New Project → Название: `figma-design-system` → Create
3. SQL Editor → New Query → Вставьте код из `supabase-schema.sql` → Run
4. Settings → API → Скопируйте **URL** и **anon key**

### 2️⃣ Figma (1 минута)
1. Figma → Settings → Personal access tokens → Create new token
2. Скопируйте токен
3. Откройте файл дизайн-системы → Скопируйте ID из URL

### 3️⃣ GitHub (1 минута)
1. https://github.com → New repository
2. Название: `figma-design-system-extractor`
3. Распакуйте архив → Загрузите файлы

### 4️⃣ Netlify (1 минута)
1. https://netlify.com → Sign up через GitHub
2. Add new site → Import from GitHub → Выберите репозиторий
3. Deploy site → Готово!

## Первый запуск

1. Откройте URL от Netlify
2. Введите все ключи и ID
3. Нажмите "Синхронизировать с Figma"
4. Дождитесь завершения (может занять несколько минут)
5. Нажмите "Сохранить в Supabase"

## ✅ Готово!

Теперь данные вашей дизайн-системы в Supabase и готовы к использованию!
