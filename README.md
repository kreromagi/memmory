# 🎨 Figma Design System Extractor

Приложение для извлечения и анализа данных дизайн-систем из Figma с автоматическим сохранением в Supabase.

## 📋 Что извлекает приложение

### 1. **Дизайн-токены**
- 🎨 **Цвета**: все цвета из заливок (fill) и обводок (stroke)
- 📝 **Типографика**: шрифты, размеры, начертания, межстрочные интервалы
- 📏 **Отступы**: padding, margins, itemSpacing
- 🔘 **Скругления**: все значения border-radius
- 🌑 **Тени**: все shadow эффекты с параметрами

### 2. **Структура страниц**
- Автоматическая категоризация по типу (colors, typography, components, etc.)
- Извлечение текстового контента
- Список всех компонентов на странице
- Идентификация руководств и примеров

### 3. **Компоненты**
- Все компоненты и варианты
- Описания компонентов
- Примеры использования

## 🚀 Пошаговая инструкция для дизайнера

### Шаг 1: Подготовка Supabase

1. **Зарегистрируйтесь в Supabase:**
   - Перейдите на https://supabase.com
   - Нажмите "Start your project"
   - Войдите через GitHub

2. **Создайте новый проект:**
   - Нажмите "New Project"
   - Введите название: `figma-design-system`
   - Придумайте пароль базы данных (сохраните его!)
   - Выберите регион (ближайший к вам)
   - Нажмите "Create new project"
   - ⏳ Подождите 2-3 минуты, пока создастся проект

3. **Создайте базу данных:**
   - В левом меню выберите "SQL Editor"
   - Нажмите "New Query"
   - Откройте файл `supabase-schema.sql` из проекта
   - Скопируйте всё содержимое файла
   - Вставьте в SQL редактор
   - Нажмите "Run" (или Ctrl+Enter)
   - Вы должны увидеть сообщение об успешном выполнении

4. **Получите ключи доступа:**
   - В левом меню выберите "Project Settings" (шестеренка)
   - Перейдите в "API"
   - Скопируйте:
     - **URL** (например: `https://xxxxxx.supabase.co`)
     - **anon/public key** (длинный токен начинающийся с `eyJhbGc...`)

### Шаг 2: Получение Figma API ключа

1. **Откройте Figma:**
   - Перейдите на https://www.figma.com
   - Войдите в свой аккаунт

2. **Создайте Personal Access Token:**
   - Нажмите на ваше имя в верхнем левом углу
   - Выберите "Settings"
   - Прокрутите вниз до раздела "Personal access tokens"
   - Нажмите "Create new token"
   - Введите название: `Design System Extractor`
   - Нажмите "Create token"
   - ⚠️ **ВАЖНО**: Скопируйте токен сразу! Он больше не покажется!

3. **Найдите ID вашего файла:**
   - Откройте ваш файл с дизайн-системой в Figma
   - Посмотрите на URL в браузере
   - Он выглядит так: `https://www.figma.com/file/ABC123DEF456/Design-System`
   - ID файла — это `ABC123DEF456` (часть между `/file/` и следующим `/`)

### Шаг 3: Загрузка проекта на GitHub

1. **Создайте репозиторий:**
   - Перейдите на https://github.com
   - Нажмите на "+" в правом верхнем углу → "New repository"
   - Введите название: `figma-design-system-extractor`
   - Выберите "Public" или "Private"
   - Нажмите "Create repository"

2. **Загрузите файлы:**
   - Скачайте ZIP архив этого проекта
   - Распакуйте его на вашем компьютере
   - Перейдите в папку в терминале/командной строке
   - Выполните команды:

   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_USERNAME/figma-design-system-extractor.git
   git push -u origin main
   ```

### Шаг 4: Деплой на Netlify

1. **Зарегистрируйтесь в Netlify:**
   - Перейдите на https://www.netlify.com
   - Нажмите "Sign up"
   - Войдите через GitHub

2. **Создайте новый сайт:**
   - Нажмите "Add new site" → "Import an existing project"
   - Выберите "Deploy with GitHub"
   - Найдите ваш репозиторий `figma-design-system-extractor`
   - Нажмите на него

3. **Настройте деплой:**
   - Build command: `npm install && npm run build`
   - Publish directory: `dist`
   - Нажмите "Deploy site"
   - ⏳ Подождите 2-3 минуты

4. **Получите URL вашего приложения:**
   - После деплоя вы увидите адрес типа: `https://random-name-123.netlify.app`
   - Можете изменить название: Site settings → Change site name

### Шаг 5: Использование приложения

1. **Откройте ваше приложение:**
   - Перейдите по URL из Netlify

2. **Введите настройки:**
   - **Figma API Key**: вставьте токен из Шага 2
   - **Figma File ID**: вставьте ID файла из Шага 2
   - **Supabase URL**: вставьте URL из Шага 1
   - **Supabase Anon Key**: вставьте ключ из Шага 1

3. **Синхронизируйте данные:**
   - Нажмите кнопку "📥 Синхронизировать с Figma"
   - Следите за логами — вы увидите прогресс
   - ⏳ Процесс может занять несколько минут в зависимости от размера файла
   - ⚠️ Между запросами автоматически добавляется задержка 7 секунд (лимит Figma)

4. **Сохраните в Supabase:**
   - После успешного извлечения появится кнопка "💾 Сохранить в Supabase"
   - Нажмите её
   - Данные сохранятся в вашей базе

5. **Скачайте JSON (опционально):**
   - Кнопка "💿 Скачать JSON" позволит сохранить данные локально
   - Это резервная копия на случай проблем с базой

## 🔧 Технические детали

### Ограничения Figma API
- ⚠️ Максимум 5 МБ данных за запрос
- ⚠️ Максимум 9 запросов в минуту
- ⚠️ Приложение автоматически делает паузы 7 секунд между запросами

### Структура данных в Supabase

#### Таблица `design_systems`
```
- id: уникальный идентификатор
- figma_file_key: ID файла в Figma
- file_name: название файла
- last_modified: дата последнего изменения
- last_sync: дата последней синхронизации
- design_tokens: JSON с дизайн-токенами
```

#### Таблица `design_system_pages`
```
- id: уникальный идентификатор
- design_system_id: связь с основной таблицей
- page_id: ID страницы в Figma
- page_name: название страницы
- page_type: тип страницы (colors, typography, etc.)
- content: текстовый контент
- components: список компонентов
- guidelines: руководства
- examples: примеры
```

## 🤖 Подключение к нейросети

После извлечения данных в Supabase, вы можете использовать их в вашей нейросети:

### Пример подключения (Python):
```python
from supabase import create_client

supabase = create_client(
    "YOUR_SUPABASE_URL",
    "YOUR_SUPABASE_KEY"
)

# Получить дизайн-систему
data = supabase.table('design_systems').select('*').execute()

# Получить конкретные страницы
pages = supabase.table('design_system_pages').select('*').eq('page_type', 'components').execute()
```

### Пример подключения (JavaScript):
```javascript
import { createClient } from '@supabase/supabase-js'

const supabase = createClient(
  'YOUR_SUPABASE_URL',
  'YOUR_SUPABASE_KEY'
)

// Получить дизайн-систему
const { data } = await supabase
  .from('design_systems')
  .select('*')

// Поиск по контенту
const { data: searchResults } = await supabase
  .from('design_system_pages')
  .select('*')
  .ilike('content', '%button%')
```

## 🆘 Решение проблем

### "Ошибка 403" при запросе к Figma
- ✅ Проверьте правильность API-ключа
- ✅ Убедитесь, что у вас есть доступ к файлу
- ✅ Попробуйте создать новый токен

### "Ошибка сохранения в Supabase"
- ✅ Проверьте правильность URL и ключа
- ✅ Убедитесь, что выполнили SQL скрипт из `supabase-schema.sql`
- ✅ Проверьте настройки RLS (Row Level Security) в Supabase

### "Too many requests"
- ✅ Это нормально! Figma ограничивает количество запросов
- ✅ Приложение автоматически делает паузы
- ✅ Просто подождите — процесс продолжится

### Приложение не открывается на Netlify
- ✅ Проверьте логи деплоя в Netlify
- ✅ Убедитесь, что все файлы загружены на GitHub
- ✅ Попробуйте пересоздать деплой
