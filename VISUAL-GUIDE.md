## 🔄 Процесс синхронизации (схема)

```
   Вы нажимаете кнопку
          ↓
   [📥 Синхронизировать]
          ↓
   Приложение → Figma API
          ↓
   ┌─────────────────────────────────┐
   │  Страница 1 (Colors)            │  ← Запрос 1
   │  Страница 2 (Typography)        │  ← Запрос 2 (через 7 сек)
   │  Страница 3 (Components)        │  ← Запрос 3 (через 7 сек)
   │  ...                            │
   │  Страница N                     │  ← Запрос N (через 7 сек)
   └─────────────────────────────────┘
          ↓
   Анализ данных
   • Извлечение цветов
   • Извлечение шрифтов
   • Извлечение компонентов
   • Извлечение отступов
          ↓
   Показ предпросмотра
          ↓
   Вы нажимаете [💾 Сохранить]
          ↓
   Данные → Supabase
          ↓
   ✅ Готово!
```

## 💡 Полезные горячие клавиши

```
В терминале:
Ctrl + C  ─  Прервать команду
Ctrl + V  ─  Вставить
↑ / ↓     ─  История команд

В браузере:
F12       ─  Открыть DevTools
Ctrl + S  ─  Сохранить файл
Ctrl + F  ─  Поиск на странице
Ctrl + R  ─  Обновить страницу

В Supabase SQL Editor:
Ctrl + Enter  ─  Выполнить запрос
Ctrl + /      ─  Комментарий
```
